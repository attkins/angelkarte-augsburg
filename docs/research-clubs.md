# Research: clubs and day tickets

Status: second pass, 2026-11-13. First pass was 2026-11-10. Prices change yearly, so every entry needs a "last checked" date in the data.

Confidence levels used below:
- official = club website, club PDF or hejfish listing
- shop = a sales point's own price list (Augsburger Angelcenter page, about one year old)
- community = alleangeln.de, monsterfisch.de, fisch-hitparade.de and similar (user generated, often outdated)

When official and shop prices differ, the official one wins. The shop list is still useful because it shows which clubs a shop sells for.

Website: https://lfv-augsburg.de

## Takeaways for the data model

- Ticket availability needs more than yes or no: "open to guests", "guests only with member", "members only", plus seasonal limits (e.g. Lech only 15 Jul to 31 Oct)
- Prices differ for member, guest, youth, guest youth
- Deposits are common (2.50 € to 5 €) and often come with a return deadline
- Sales points are shared across clubs (Augsburger Angelcenter sells for nine clubs, Jafispo and Fisherman's Partner for several), so they stay their own entity
- A sales point does not always sell for all waters of a club (FVA matrix), so the link has to be per water, as it already is
- Online purchase can be hejfish or Angelroute, so store a platform name plus link
- Some waters are fly fishing only
- Some tickets are only valid on certain weekdays (Zusmarshausen) or only for event days (Haunstetten Badfischen)
- Prices can carry a validity year (FVA list is for 2027)
